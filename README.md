# Атлас разводов

Интерактивная страница о разводах: карта мира, Беларусь, штаты США, цепочки причин с доказательствами, досье исследований и длительность брака.

Смотреть: https://rozzhalovetsolga.github.io/divorce-atlas/

Данные: национальные статслужбы, Eurostat, US Census (ACS), CDC, Всемирный банк, ВОЗ и научные исследования. Источники указаны на странице у каждого показателя.
